      CSV Coordinates to KMZ File

      Update matching point placemarks in a KMZ or KML from a spreadsheet export.

      Set a CSV or Excel file (.csv, .xlsx, .xlsm, .xls) with borehole id, latitude, and longitude columns (any common spelling, such as BH_ID / Borehole / boring_id, LAT / Latitude, and LONG / Longitude), and the KMZ or KML to update. Each point placemark must have <Point><coordinates>. Match CSV rows by ExtendedData BH_ID or by <name> (e.g. B6A). Preview changes before applying them to the open file. BH_ID matching tolerates common spelling differences (e.g. B6A vs B-6A, B06A, or BH-6A).
